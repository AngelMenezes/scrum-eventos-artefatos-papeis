# Desafio Scrum Framework

Este repositório reúne a resolução de um desafio prático sobre os fundamentos do Scrum, feito em quadro colaborativo.

O desafio tem três atividades:

1. **Classificação de cards:** mover os post-its da "mesa" para as colunas corretas (Scrum Team, Eventos e Artefatos), identificando as "pegadinhas" que não fazem parte do Scrum, como Project Manager, Rugby, To do List, Stakeholders e Project Release.
2. **Scrum Framework:** preencher o diagrama com todos os eventos, artefatos e papéis, considerando uma Sprint de 4 semanas e os timeboxes máximos de cada evento (Planning 8h, Daily 15 min, Review 4h e Retrospective 3h).
3. **Pilares e Valores:** mapa mental com os 3 pilares (Transparência, Inspeção e Adaptação) e os 5 valores do Scrum (Compromisso, Foco, Abertura, Respeito e Coragem).
